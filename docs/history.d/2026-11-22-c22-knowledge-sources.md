| (this change) | Knowledge sources (C22). An agent's knowledge base can be kept in sync with a folder of the files directory, an S3 prefix (new `s3Api` credential), one website (same host, depth 3, 500 pages, robots.txt, 500 ms between requests, private start addresses refused in production) or a Google Drive folder (the person's own Connect). Each source has a schedule (manual, hourly, daily), Pause, Sync now and a history of runs with counts and failed items. A sync compares version markers and writes only what changed through the C20 re-index as the base's home project, and removes items only when the listing was complete. The claim is decided in Postgres, a lease of five minutes with a heartbeat, split from the source row (migration 2929); scheduled syncs run on the leader. Removing a source asks whether to delete its chunks.
