| (this change) | **Dynamic secrets with leases (C30).** An OpenBao or Vault provider gets **Dynamic mounts** (`database/`) and a **Lease TTL**: a `$secrets` path under a dynamic mount, `{{ $secrets.bao['database/creds/report-reader'].password }}` in a node's credential, is issued instead of read. The first node of a run that needs it asks the store's database engine for a user (resolution happens at that node, so a run that fails earlier issues nothing); every node of the run gets the same one, another run gets its own. Each lease is a row in the new `secret_leases` table (migration 2933) with its lease id and issued values sealed and re-sealed by key rotation, dropped when it ends; the values never enter the value cache and are redacted like every secret. The lease is revoked when the run ends (any status; a waiting run keeps it), and a leader service, the **lease sweeper**, revokes the leases of runs that are over or gone, ends leases that ran out while a run waited, renews a running run's lease by the Lease TTL up to an hour, retries refused revokes on a backoff and, after 24 hours, marks them `revoke_failed` with an audit event and a banner. Settings → External secrets → **Leases** lists them with **Revoke now** and **Revoke run**; `GET /api/external-secrets/leases` and `POST /api/external-secrets/leases/revoke` are in the API reference. A dynamic path outside a node credential (Test connection, agents, alerts, OAuth2 Connect, node parameters) is refused. New fake `@landflow/test-fakes/vault-leases`, the local engine script `deploy/scripts/openbao-db-engine.sh` and an integration test against the real engine. Review fixes: a lease written by one process is announced to the others (the leader's sweeper, lists, counts and key rotation see a worker's lease); only the run the engine names gets leases (not agent channels, MCP lists or run changes); an unsealable lease id is a failed revoke; ended leases are never written back to active; renew failures and revoke attempts are counted apart and non-renewable leases are not renewed; values are sealed per row; the lease routes are for the built-in owner and admin. | [features/secrets-and-environments.md](features/secrets-and-environments.md#dynamic-secrets) |
