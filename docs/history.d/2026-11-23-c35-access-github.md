section: 2026-11-23: access requests
| (this change) | **GitHub grant actions (C35, part 1).** A second node in the GitHub plugin, **GitHub Access** (`github.githubAccess`), grants and takes back access: Team Membership (add with member or maintainer, remove, get members, get membership), Organization Membership (invite by login or email, get, remove, cancel invitation), Repository Collaborator (add with pull, triage, push, maintain or admin, remove, get collaborators, get permission; an outside user is invited and shows as `pending`) and Project (v2) Collaborator (add, remove, through GraphQL `updateProjectV2Collaborators`; `changed` is null there, as GitHub does not say, and there is no list). Every result is `{ user, target, role or permission, state, changed }`; the writes read first and are idempotent, a 404 names what is missing (team, organization, repository, user) and a 403 or 422 explains scopes and roles. Only the reads are agent tools; every write is `mcp: false`. The plugin's fake grew an access half (memberships, invitations, collaborators, a Projects GraphQL endpoint) and 38 tests cover it. | [features/integrations.md](features/integrations.md) |
