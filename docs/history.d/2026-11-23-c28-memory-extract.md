| (this change) | **Memory Extract and a sampled Memory Profile (C28).** A new AI node, `core.memoryExtract`, turns text and a reference date into one item per atomic, self-contained fact (`statement`, `subject`, `kind`, `validAt`, `confidence`, `sourceSpan`) with the chat model on its input; Landflow works out the relative dates it knows (last Monday, two weeks ago, next quarter) itself and drops any model date that is not real or is more than ten years away. Each fact is compared with the memory's five nearest items and labelled `new`, `updates` or `duplicate`; with Write to Memory on, new facts are added and updates are written as the next version (the old one kept), with the model's confidence and the run, node, document, date and source span as evidence. Memory Profile gains Sampled: every static fact plus a weighted sample of the others as Markdown inside a token budget, saying how many were left out. Memory items carry `confidence`, `origin` and `evidenceCount`, and Memory Add takes `confidence` and up to six `evidence` rows (also sent to a memory provider).
