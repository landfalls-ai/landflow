section: 2026-11-23: Decide node
| (this change) | **Decide node review fixes (C34).** Editing a Decide's options no longer re-routes connections: `remapExpandedConnections` (protocol) keeps each connection on the output of the same name (an option, Unsure, Yes, No), follows an in-place rename and removes the connection of a name that is gone; the editor store and Spotlight's `setParameters` use it, and a save-time warning names a connection from an output that no longer exists. Every place that counted a node's outputs (Spotlight's connect and placement, the builder's catalog and connection check, the node docs) now counts the expanded ones. The node keeps an item's binary data, caps What To Read at 32,000 characters with a message that suggests narrowing it, reads only an object or array typed into What To Read as JSON, refuses an option called Unsure, offers Route By as a list of the Choice and Yes/No questions, and does not let a question's instructions be an expression. A plugin manifest that uses the `expand` port rule is refused; the JSON schemas are regenerated. Spotlight's Decide format line shows the connections for each option and says to leave What To Read as `{{ $json }}` unless a field is named. | [features/ai.md](features/ai.md#decide) |
