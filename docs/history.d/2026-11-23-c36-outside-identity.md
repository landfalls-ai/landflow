section: 2026-11-23: access requests
| (this change) | C36-A: people without a Landflow account can sign in to ask for access. An admin switches it on in `/api/access/outside` (off by default, allowed email domains, optional Google sign-in with a new `oidcClient` credential). A person gets a one-time email link (SHA-256 only, 15 minutes, single use by one conditional update, the same answer for every address, limits per address, domain and network address) or signs in with Google (code flow with PKCE, state, nonce, `email_verified`, an allowed `hd` equal to the address's domain, the Google subject pinned), and gets a requester session (cookie `landflow_requester`: HttpOnly, SameSite=Strict, `Path=/request-access`, 8 hours, 2 hours idle) that opens nothing of Landflow's. An address that belongs to a Landflow user gets no outside identity. Same-origin JSON checks on every public write; admins list and Block requesters; every step is audited (`access.outside.*`). Migration 2936; Landflow's SSO now shares its code flow (`beginCodeFlow` / `finishCodeFlow`) with this one | [access-requests.md](access-requests.md#signing-in-without-an-account) |
