# W3 notes: Browser node editor experience and output

For the integrator. Nothing here is in `history.md`, `roadmap.md`, `limitations.md` or `docs/README.md` yet.

## Feature page text (for the Browser plugin entry; the full text is in `plugins/browser/README.md`)

The Browser node's Act on Page operation takes **Steps** as a list built in the editor (action, target, text) beside a **Steps (JSON)**
box; the list runs first. **Extract** steps (`getText`, `getValue`, `getAttr`) read a value into `results: { name: value }`, so the next
node reads `{{ $json.results.confirmation }}`. Each step reports `{ action, target, ok, ms }` in `steps`, and a failure names the step.
**Screenshot After Steps** attaches a PNG. **Allowed Domains** defaults to the URL's own site, with a notice; **Show the Browser Window**
sits beside it. Extracted text is untrusted page content: content boundaries and the allow-list stay on, the snapshot stays fenced, and
`getText` values in `results` are unwrapped from the CLI's nonce fence so a flow can use them.

## Limitations line

The Browser node's `results` hold unfenced page text (the CLI's boundary marker is removed from `getText` values); an agent that reads
`results` must treat them as untrusted, and there is no option yet to keep the fence on them. A failed step stops the node, so the per-step list
(`steps`) reaches the output only when every step succeeded; on failure the step is named in the error. Extract Attribute in the builder takes
`name:attribute` in one text field.

## Roadmap line

Browser node: step builder, Extract steps, per-step results, screenshot after steps and a host-defaulted allow-list (W3). Open: a
"continue on step failure" mode that returns the partial `steps`, and an option to keep fences on extracted text.

## Item 4, the output-panel PNG preview: nothing to build

The host already previews images: `apps/web/src/components/run/binary-view.tsx` (the DataView Binary tab) renders an `<img>` for any
`image/*` binary and opens a single image by default. So the screenshot-after-steps PNG shows there with no editor change. No file under
`apps/web/src/components/editor/` was touched.
