# Notes for the integrator: P24 `llms` (C25)

- `docs/README.md`: a "Publishing a page" paragraph and a feature-map line.
  - Paragraph: the docs agents read are listed in `docs/published.json`, in reading order, in sections; each entry has `path`, `title` (the page's first `# ` heading, exactly), a one-line `description` (up to 160 characters) and `full` (`true` puts the page's text into `llms-full.txt`; `false` links `llms.txt` to the page in the repository). A page that is not listed is not published and is printed once as "not published" by `pnpm check:docs`. Run `pnpm docs:llms` after changing the manifest and commit `docs/llms.txt`; `docs/llms-full.txt` is built and never committed. The check refuses a manifest entry under `specs/`, `research/`, `history.md`, `constitution.md` or the manifest's `internal` list; a link from a `full` page into one of those (a link to any other unpublished page or to a file outside `docs/` becomes its words); a title that does not match; a stale `llms.txt`; a home-folder path, an email address outside example.com, example.org, example.net and `.test`, a `Claude-Session` or claude.ai session link, a secret-looking token or an internal hostname in any published page; and `llms.txt` over 20 KB or `llms-full.txt` over 1.5 MB (it names the three largest pages: set `full` to `false` on one).
  - Feature-map line: "Docs for agents: `/llms.txt` and `/llms-full.txt` on every host (public, cached an hour), built from `docs/published.json`" | [reference/configuration.md](reference/configuration.md) (`LANDFLOW_LLMS_DIR`) | `scripts/llms.mjs`.
- `docs/development.md`: `pnpm docs:llms` writes the two files, `pnpm check:docs` is in `pnpm check` (after `check:history`); `scripts/llms.test.mjs` (in `pnpm test:scripts`) and `apps/web/test/llms-route.test.ts` are the tests; the host image's build stage runs `node scripts/llms.mjs --write` and copies the two files to `apps/web/llms/`.
- `docs/limitations.md`:
  - The host serves the two files only: no page of its own is served at a URL (`llms.txt` links into `llms-full.txt` anchors, and pages outside the full set link to the repository on GitHub).
  - `llms-full.txt` holds 1.1 MB of the 1.5 MB cap; `agents.md` and `reference/api.md` grow each wave. Pages outside the full set (deployment, the assistant, the LLM gateway, the second brain, Run Trace and others) are listed in `llms.txt` only; `limitations.md`, `roadmap.md`, `history.md`, `development.md` and the constitution are not published at all.
  - A link from a published page to an unpublished page loses its link in `llms-full.txt` (the words stay); a link to an anchor that is not a heading of the target keeps the page's anchor only.
  - The image build was not run for this change (the Dockerfile lines are the only untested part).
